# FreeScribe AI Transparency & User Guide
- **System Type**: AI Clinical Scribe
- **Hardware**: Runs locally on macOS via Whisper (No cloud data transfer)
- **Instruction**: Clinicians must verify all summaries before saving to patient records

# AI Disclosure Mechanism
- **Notification**: Users are informed via UI that AI is active
- **Labeling**: All generated files are prefixed with an 'AI-Generated' warning
